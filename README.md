# video-analysis.nvim

動画やドラマなどの視聴分析・チャプタータイムスタンプ記録用 Neovim プラグイン。

動画を見ながら Neovim 上で直感的に経過時間を計測し、チャプターリスト（`0:00:00 - 0:02:15: chapter 1` 形式）を自動入力できます。
動画の早送り・巻き戻し時の時間修正や一時停止にも対応しています。

---

## ✨ 主な機能

- **バッファローカルなモード切替**: 通常の Neovim 操作（SやSpaceキー）と競合しないよう、`:VideoAnalysis` を実行したバッファでのみキーが有効化されます。
- **ワンキーでのチャプター記録**: `<Space>` を押すだけで、前回のチャプター終了時刻から現在時刻までの区間を自動入力します。
- **動画スキップ・早送り対応**: `C` キーでいつでも動画の再生位置（`H:MM:SS`, `MM:SS`, 秒数）に合わせてタイマーを同期できます。
- **一時停止・再開**: `P` キーで動画のストップに合わせて計測を一時停止できます。
- **自動終了記録**: `E` キーを押すと、最後の区間を自動記録してモードを終了し、通常キーに復帰します。

---

## 📦 インストール方法

### LazyVim / lazy.nvim をお使いの場合

ローカルプラグインとして読み込む設定例（`~/.config/nvim/lua/plugins/video-analysis.lua` 等に配置）：

```lua
return {
  {
    dir = "~/Projects/nvim/video-analysis.nvim",
    cmd = { "VideoAnalysis", "VideoAnalysisStart", "VideoAnalysisStop" },
    opts = {
      -- オプション（デフォルト設定）
      chapter_format = "%s - %s: chapter %d",
      keymaps = {
        start = "S",
        next = "<Space>",
        pause = "P",
        change_time = "C",
        stop = "E",
      },
    },
  },
}
```

## 🚀 使い方

1. メモや分析結果を書きたいバッファ（Markdownやテキスト等）を開きます。
2. `:VideoAnalysis`（または `:VideoAnalysisStart`）を実行します。
   - 分析モードが有効化され、専用のキーマッピングがセットされます。
3. **`S`** を押して動画視聴を開始します（タイマーが `0:00:00` から計測開始）。
4. チャプターを区切りたいタイミングで **`<Space>`** を押します。
   - カーソル行（空行ならその行、文字があれば直下）に以下のように入力されます：
     ```text
     0:00:00 - 0:03:20: chapter 1
     ```
   - 次に `<Space>` を押したときは前回の終了時刻が引き継がれます：
     ```text
     0:03:20 - 0:08:45: chapter 2
     ```
5. 動画を早送り・スキップしたときは **`C`** を押します。
   - プロンプトが表示されるので、動画の再生位置を入力します（例: `0:15:30` や `15:30`）。
   - Enter を押すと入力した時刻から自動でカウントが再開され、次のチャプター開始時刻も更新されます。
6. 動画を一時停止するときは **`P`** を押します（もう一度押すと再開）。
7. 動画を見終わったら **`E`** を押します。
   - 最後の区間が自動記録され、タイマーが停止してキーバインドが通常に戻ります。

> **途中でキャンセル・強制終了したい場合:**
> コマンド `:VideoAnalysisStop` を実行すると、記録を挿入せずに安全にモードを解除できます。

## ⚙️ 設定オプション

```lua
require("video-analysis").setup({
  -- 出力フォーマット（start, end, index）
  chapter_format = "%s - %s: chapter %d",

  -- キーマップ
  keymaps = {
    start = "S",          -- タイマースタート
    next = "<Space>",     -- チャプター記録＆次へ
    pause = "P",          -- 一時停止 / 再開
    change_time = "C",    -- 時間変更（シーク・早送り）
    stop = "E",           -- 最終チャプター記録＆終了
  },
})
```
